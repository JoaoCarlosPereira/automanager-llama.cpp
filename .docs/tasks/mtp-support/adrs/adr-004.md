# ADR-004: Organização de helpers MTP em gpu_manager e process_manager

## Status

Aceito

## Data

2026-06-07

## Contexto

A feature MTP exige detecção de compatibilidade (I/O com llama-server) e montagem de flags CLI. O codebase já separa essas responsabilidades para features similares: `gpu_manager.detect_model_layers()` para introspecção de modelo e `process_manager.reasoning_cli_args()` para construção de argumentos CLI.

## Decisão

- **`gpu_manager.detect_model_mtp(model_path)`** — detecção de compatibilidade via `--model-info`.
- **`process_manager.mtp_cli_args(mtp_enabled, mtp_draft_tokens, model_path, gpu_manager)`** — retorna lista de flags CLI ou `[]` quando MTP não deve ser aplicado (toggle off ou modelo incompatível).

Constantes em `config_manager.py` e `schemas.py`:
- `DEFAULT_MTP_ENABLED = False`
- `DEFAULT_MTP_DRAFT_TOKENS = 3`
- `MTP_DRAFT_TOKENS_MIN = 1`
- `MTP_DRAFT_TOKENS_MAX = 6`

## Alternativas Consideradas

### Alternativa 1: Tudo em process_manager.py

- **Descrição**: Detecção e flags CLI no mesmo módulo.
- **Prós**: Um único arquivo a editar no start.
- **Contras**: process_manager já grande; mistura lifecycle com introspecção de GGUF.
- **Por que rejeitada**: Quebra separação estabelecida com detect_model_layers.

### Alternativa 2: Novo módulo mtp_utils.py

- **Descrição**: Módulo dedicado para MTP.
- **Prós**: Isolamento total.
- **Contras**: Over-engineering para duas funções; viola YAGNI da skill.
- **Por que rejeitada**: Escopo MVP não justifica novo pacote/módulo.

## Consequências

### Positivas

- Consistência arquitetural com thinking_enabled / reasoning_cli_args.
- Testabilidade: testes unitários separados para detecção vs montagem de flags.
- Extensão futura (cache, spec-draft-p-min) localizada.

### Negativas

- `mtp_cli_args` precisa receber gpu_manager ou model_path para invocar detecção.

### Riscos

- Acoplamento leve entre process_manager e gpu_manager — já existente e aceito.

## Notas de Implementação

Assinatura proposta de `mtp_cli_args`:

```python
def mtp_cli_args(
    mtp_enabled: bool,
    mtp_draft_tokens: int,
    model_path: str,
    gpu_manager: GPUManager,
) -> List[str]:
    ...
```

Retorno quando aplicável: `["--spec-type", "draft-mtp", "--spec-draft-n-max", str(n)]`.
