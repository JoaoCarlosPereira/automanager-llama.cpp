# ADR-005: Pac-Man Background Integration — Fixed Overlay

**Date:** 2026-05-19  
**Status:** Accepted  
**Context:** The `design/` directory contains a Pac-Man themed Canvas animation (`scripts.js`) with background grid, circuit nodes, Pac-Man character, ghosts, pellets, and sparks. We need to integrate this as a visual accent in the manager UI without disrupting functionality or performance.  
**Decision:** Position the Pac-Man Canvas as a fixed background layer with `position: fixed; z-index: 0; top: 0; left: 0; width: 100vw; height: 100vh; opacity: 0.35; pointer-events: none`. The dashboard content sits above at `z-index: 1` with existing glass-morphism styling. The canvas respects `prefers-reduced-motion` (renders static). The animation uses throttled FPS (target 30fps) to minimize CPU impact.  
**Alternatives Considered:**
- **Conditional toggle:** Add a UI toggle button. Adds UI complexity and state management for a purely cosmetic feature.
- **Config-based:** Require editing JSON config to enable. Poor UX for a visual feature that should be discoverable.
**Consequences:**
- Always-on visual enhancement without user interaction needed
- Low performance impact (30fps cap, reduced opacity, `pointer-events: none`)
- Respects accessibility (`prefers-reduced-motion`)
- Canvas is independent of dashboard JS — no coupling
- No additional dependencies — JS extracted from `design/js/scripts.js`
- If canvas fails to load (JS error), dashboard remains fully functional
