# ADR-001 — Abordagem de Análise: Híbrida (Camada + Fluxo)

**Data:** 2026-06-10
**Status:** Aceito
**Autores:** Análise Automanager Performance

## Contexto

O gerenciador llama-server (automanager) precisa de uma análise profunda de performance para operar como uma central de desempenho máximo dos modelos que gerencia. A análise deve cobrir toda a gama de modelos (1B a 30B+), hardware multi-GPU PCIe e contextos mistos (4K a 65K+ tokens). O objetivo principal é maximizar throughput (tokens/segundo).

## Decisão

Adotar a **Abordagem C — Análise Híbrida**, combinando:

1. **Mapeamento horizontal por fluxo:** Seguir cada fluxo do gerenciador (inicialização → detecção GPU → offloading → spawn → runtime → OOM recovery) e identificar otimizações em cada ponto de contato com o llama-server.
2. **Matriz vertical por camada:** Dentro de cada ponto do fluxo, aplicar uma matriz de otimizações organizadas por camada técnica (GPU/CUDA, KV cache/memory, batching, NUMA/SO, networking, model discovery).
3. **Priorização por impacto no throughput:** Classificar cada recomendação com nível de impacto (crítico, alto, médio, baixo) no throughput.

## Alternativas Consideradas

### Abordagem A — Vertical por Camada
Focar em cada camada de otimização em profundidade isoladamente.
- **Rejeitada porque:** Pode perder otimizações transversais que afetam múltiplos fluxos e não mapeia diretamente com o código existente.

### Abordagem B — Horizontal por Fluxo
Seguir cada fluxo do gerenciador e identificar otimizações em cada ponto de contato.
- **Rejeitada porque:** Pode perder otimizações transversais que afetam múltiplos fluxos e não organiza as recomendações por impacto técnico.

## Consequências

- A análise será organizada em duas dimensões: fluxos do gerenciador × camadas técnicas.
- Cada recomendação terá uma localização direta no código (arquivo + função) e um nível de impacto no throughput.
- O PRD resultante terá estrutura clara para implementação incremental, com priorização natural por impacto.
- Documento mais extenso, mas com maior cobertura e acurácia técnica.
